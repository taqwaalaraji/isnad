# Glossary

The terms used in the interface, Arabic first.

| Arabic | English | Meaning |
|---|---|---|
| إسناد | Isnad | The product. In Arabic scholarship, the chain of narrators behind a report; here, the chain from a number back to its official source. |
| لكلّ رقمٍ إسناد | Every number has an isnad | The tagline |
| تحقق | Check | One submission (clip, audio, document, link or text) and its results |
| رقم / ادعاء | Number / claim | A number stated in the content, with what it measures and for which period |
| لم يُتحقق منها | Not checked | Opinions and forecasts that can't be checked against an official source |
| مطابق للمصدر | Matches source | Number, period and scope as in the official document |
| سياق مختلف | Different context | The number is right, but the period, scope or unit differs |
| مختلف عن المصدر | Differs from source | The number doesn't match the official document for the same period and scope |
| لم يُعثر على مصدر | No source found | No official document supports the number (not necessarily wrong) |
| لم يُبحث بعد | Not searched yet | Not in the registry and not yet searched on official sources |
| السند | Chain (isnad chain) | Official document → relay → this content |
| السند متصل | Connected chain | Reaches an original official document (tier 1 or 2) |
| السند منقطع | Broken chain | Breaks before an original official document |
| الشاهد | Evidence | The verbatim quote or table cell in the official document |
| الوثيقة الرسمية | Official document | The document a figure comes from, stored as published |
| ناقل | Relay | A party that passes a number on (e.g. a news agency) |
| المستوى 1 · الأصل | Tier 1 · Origin | Produces the statistic |
| المستوى 2 · المُصدِر | Tier 2 · Issuer | Publishes its own official numbers |
| المستوى 3 · ناقل | Tier 3 · Relay | Relays others' numbers |
| سجل الإسناد | Isnad Registry | What official sources said, when and where |
| مؤشر | Indicator | What is measured (e.g. international visitors) |
| جهة | Entity | Who publishes or is quoted (e.g. a statistics centre) |
| مصدر | Source | One outlet of an entity, with its approved web domains |
| موضوع | Topic | A subject area (tourism, trade, …) |
| اسأل إسناد | Ask Isnad | Questions answered from the registry only, with evidence |
| الصياغة المقترحة | Suggested wording | A sentence with the official value and attribution |
| ملاحظة المدقق الآلي | Automatic verifier note | A second, independent model check of the evidence |
| بحاجة لقرار فقط | Needs a decision only | Filter for undecided numbers |
| اعتماد | Approve | Accept a number (or a whole check) |
| تعديل | Edit | Approve with a corrected wording |
| إحالة | Escalate | Send a number to the responsible editor |
| إعادة فتح | Reopen | Undo a decision |
| إرسال للمراجعة | Send for review | Ask an editor to review a check |
| اعتماد كل المطابق | Approve all matches | Approve every matching number without a verifier objection |
| اعتماد التحقق | Approve check | Final approval once every number is decided |
| تسجيل النشر | Record publication | Save the published link; creates the public evidence page |
| ملاحظة الإسناد | Isnad note | The sources block to paste under a story |
| صفحة الشاهد العامة | Public evidence page | The readers' page for a published check |
| إعادة التحقق بسجل اليوم | Re-check against today's registry | Compare the numbers again with current official figures |
| التفريغ | Transcript | The text of a clip, line by line with times |
| تتبّع التشغيل | Follow playback | Keep the current number in view while playing |
| توقف عند كل ملاحظة | Pause at each issue | Stop playback at numbers that differ or have a different context |
| تعديل رقم رسمي | Official figure revised | Alert when a figure behind a published number changes |
| إصدار جديد / رقم جديد | New release / new figure | Alerts for what you follow |
| متابعة | Follow | Get alerts for an indicator or entity |
| الإحاطات | Briefs | Pre-interview sheets from the registry |
| غرفة الأخبار / الغرفة | Newsroom | An organization using Isnad |
| القسم | Desk | A section inside a newsroom |
| صحفي | Journalist | Newsroom role |
| محرر | Editor | Newsroom role that decides |
| مدير الغرفة | Newsroom admin | Newsroom role that manages people and policies |
| أمين السجل | Curator | Isnad staff who run the registry |
| مشرف المنصة | Platform admin | Isnad staff who run the platform |
| منصة إسناد | Isnad console | The staff workspace |
| مراجعة الأرقام | Figure review | Curators approving extracted figures |
| صندوق الوارد | Inbox | Documents added by hand to the registry |
